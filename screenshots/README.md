1. `01_login_page.png` - Login portal with demo credentials displayed.
2. `02_user_dashboard.png` - User dashboard with active request quota (BR1) and status overview.
3. `03_create_request_success.png` - Creating request with live charge calculation (BR4) and capacity preview.
4. `04_request_details_snapshot.png` - Snapshot proof (BR3) and status history audit trail.
5. `05_admin_dashboard_workflow.png` - Administrator dashboard processing statuses (BR8).
6. `06_cancellation_resource_release.png` - User cancellation releasing resource capacity once (BR9).
7. `07_active_limit_rejection.png` - Active request limit (6th request) rejection error.
8. `08_access_denied.png` - Unauthorized access protection (BR10).
